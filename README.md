# SwiftlyAI Studio Website

Agency website built with **NextJS 16 + TailwindCSS + ElysiaJS + Eden**.

## Pages
- Home page inspired by Mintlify's visual style (light, airy, grid texture, smooth cards)
- Portfolio page
- Submit Proposal page with multi-step form

## Run locally

```bash
npm install
npm run dev
```

In another terminal (requires Bun):

```bash
npm run backend
```

The proposal form submits via Eden to Elysia at `http://localhost:3001/proposals`.
