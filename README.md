# Speedy Dev Website Portfolio

Mintlify-inspired agency website built with **Next.js 16 + Tailwind CSS**, plus an **ElysiaJS** backend consumed with **Eden treaty**.

## Pages

- `/` Home page
- `/portfolio` Portfolio page
- `/proposal` Multi-step proposal submission page

## Development

```bash
npm install
npm run backend:dev
npm run dev
```

Set backend URL if needed:

```bash
NEXT_PUBLIC_API_BASE_URL=http://localhost:3001
```
